# Reading Order Generator

## ReadingOrder.ipynb
Use the Reading_Order_Generation() function to generate the output image and a Euclidean.csv file. The input parameters would be path to the image and output of the doctr file in json format.

## VideoGeneration.ipynb
Used to generate .mp4 videos of the reading order. Uses the input image as well as the Euclidean.csv file generated above as input.
